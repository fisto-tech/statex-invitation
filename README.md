# Statex® — India ITME 2026 Official Invitation

**Exhibition:** India ITME 2026 Exhibition — Greater Noida  
**Dates:** December 4th – 9th, 2026  
**Venue:** India Expo Centre & Mart, Knowledge Park II, Greater Noida, Delhi NCR, India  
**Pavilion & Stall:** Hall 9 / H9G7  
**Featured Live Showcase:** Statex Vegam System — High-Volume Fiber Tester (Length, Strength & Color Module)

---

## Features
- **VIP Exhibitor Invitation Card** with interactive envelope open/close and pass reveals
- **Interactive 360° 3D Model**: Real-time Three.js rendering of the Statex Vegam console and fiber testing station
- **Live Demo Highlights**: Statex Vegam high-speed cotton fiber quality analysis
- **Quick Action Tools**: Tap to copy stall location, add to calendar, venue directions, and contact buttons
- **Responsive Studio Design**: Custom Tailwind CSS styling with Lexend typography and high-contrast Statex branding colors (`#00bcba` and `#e30613`)

---

## Running Locally

To view the invitation locally in your browser:

```bash
# Option 1: Using npx serve
npx serve .

# Option 2: Using python
python -m http.server 3000
```

Then open `http://localhost:3000` in your web browser or double click `index.html`.
